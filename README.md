# Portfolio personnel — David Kouakou

Site vitrine bilingue (français / anglais), responsive sur mobile, tablette et ordinateur.

## Fichiers
- `index.html` : contenu et structure du site.
- `styles.css` : mise en page, couleurs, animations et responsive.
- `script.js` : menu mobile, langue FR/EN et année automatique.

## Avant la publication
1. Ouvrir `index.html` dans un navigateur pour tester le site.
2. Dans `index.html`, rechercher `ton.email@example.com` et remplacer cette adresse par une adresse que vous consultez. Vérifier aussi le lien `mailto:` dans le bouton de contact.
3. Vérifier les informations du parcours et ajuster les formulations si nécessaire.
4. Ajouter une photo plus tard si vous le souhaitez : le design actuel fonctionne sans photo.
5. Les polices Google Fonts nécessitent une connexion internet ; des polices de secours sont prévues.

## Publication gratuite avec GitHub Pages
1. Créer un compte sur https://github.com/ si nécessaire.
2. Créer un nouveau dépôt public, par exemple `portfolio-david-kouakou`.
3. Envoyer `index.html`, `styles.css` et `script.js` à la racine du dépôt (bouton **Add file** → **Upload files**).
4. Dans le dépôt, ouvrir **Settings** → **Pages**.
5. Sous **Build and deployment**, choisir **Deploy from a branch**, sélectionner la branche `main` et le dossier `/ (root)`, puis enregistrer.
6. Attendre quelques minutes. GitHub affichera l’adresse publique de votre site dans la section Pages.

## Autre option : Netlify
1. Aller sur https://www.netlify.com/ et créer un compte.
2. Depuis le tableau de bord, utiliser l’option de déploiement manuel (si elle est proposée) et déposer le dossier du site, ou connecter le dépôt GitHub.
3. Netlify fournit une URL publique. Vous pourrez ensuite configurer un nom de domaine personnalisé si vous en achetez un.

## Important
Le site est un portfolio statique : il n’a pas de base de données ni de formulaire de contact côté serveur. Le bouton de contact ouvre l’application e-mail de la personne. Remplacez l’adresse e-mail provisoire avant de publier.
